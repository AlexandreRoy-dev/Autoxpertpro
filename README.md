# AutoXpert

Chat-first parts app: Marc on the left, vendor offers to buy on the right. Québec French / English. Garage, entretien, and cart stay as secondary pages.

Live site: https://autoxpertpro.com/

```bash
npm install
npm run dev
```

Open http://localhost:3000/fr/

Copy `.env.example` to `.env.local` and add `AI_GATEWAY_API_KEY` to stream the mechanic assistant. Without the key, the catalogue matcher still answers.
